📦 What's Included (Checklist)

✅ The Core Prompt Library: 50+ High-Fidelity Prompts categorized by function.

  • Shell Scripting & Automation: Scripts for backups, monitoring checks, and cleanup tasks.
  • Infrastructure as Code (IaC): Templates/prompts for generating Terraform, CloudFormation, or Ansible playbooks based on natural language inputs.
  • Network Analysis: Prompts to diagnose common networking issues (e.g., "Simulate packet traceroute failure analysis using this input").
